# Septix Technologies - Official Corporate Website

Welcome to the official repository for **Septix Technologies**, a global IT consulting and software engineering firm delivering cutting-edge digital solutions worldwide.

## 🚀 About Septix Technologies

Septix Technologies provides end-to-end technology services to startups, enterprises, and global brands. Our core service offerings include:

1. **Website Development** (`services/website-development.php`) - High-performance web apps, single-page apps, custom CMS, and PWAs.
2. **Mobile Application Development** (`services/mobile-app-development.php`) - Native iOS (Swift), Android (Kotlin), and cross-platform (Flutter/React Native) solutions.
3. **Custom ERP Software** (`services/custom-erp-software.php`) - Enterprise Resource Planning, supply chain, HCM payroll, and custom BI dashboards.
4. **Digital Marketing** (`services/digital-marketing.php`) - Technical SEO, performance PPC, social media strategy, and conversion rate optimization.
5. **AI/ML Solutions** (`services/ai-ml-solutions.php`) - Generative AI integration, predictive analytics, NLP, and intelligent business automation.
6. **IT Networking Solutions** (`services/it-networking-solutions.php`) - Cloud infrastructure (AWS/GCP/Azure), SD-WAN, cybersecurity audits, and 24/7 SLA managed IT.

## 🛠️ Local Development & Testing

To run the Septix Technologies website locally using PHP's built-in web server:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Maulik-Dawda/septix-technologies.git
   cd septix-technologies
   ```

2. **Start the local PHP server**:
   ```bash
   php -S localhost:8000
   ```

3. **Open in Browser**:
   Navigate to `http://localhost:8000` in your web browser.
